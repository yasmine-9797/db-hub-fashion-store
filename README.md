# DB Hub Fashion Store

Build the first version of a polished, professional, futuristic-but-user-friendly fashion storefront for DB HUB CLOTH STORE. Use the user-provided Instagram screenshots as visual/brand reference if available in this conversation. Create the actual website now, not just a plan.

BRAND:
- Name: DB Hub Cloth Store
- Instagram: https://www.instagram.com/db_hub_cloth_store/
- Existing logo: burgundy dress silhouette with DB Hub lettering. Preserve this identity. If the logo image is not available as an asset, create a tasteful text logo treatment and do not invent a replacement symbol.
- Colors: burgundy #80002A, deep burgundy #4A0018, warm white #FAF8F6, near-black #171717, gray #737373, champagne #D8C3A5.
- Positioning: wholesale and retail; unisex, Korean-inspired, imported and surplus clothing. Budget-friendly, trend-aware, welcoming to all shoppers.
- Contact numbers: 9345926694 and 9363034644.
- Chennai address: Loc Square, Pycrofts Road, Narayana Krishnaraja Puram, Triplicane, Chennai, Tamil Nadu 600005.
- Coimbatore address: Brindhavan Circle, Kuniyamuthur, Coimbatore, Tamil Nadu 641008.

DESIGN:
Create a high-quality editorial fashion look with large typography, clean spacing, generous photography, burgundy accents, subtle motion, premium image-led category cards, and a refined mobile-first layout. Avoid generic template styling, excessive gradients/neon, excessive rounded cards, and clutter.

BUILD THESE SECTIONS:
1. Slim announcement bar: “TRENDING FASHION • WHOLESALE & RETAIL • CHENNAI × COIMBATORE”.
2. Responsive sticky header with brand logo, Home, Shop, New Arrivals, Collections, Wholesale, Our Stores, search and contact.
3. Strong hero with fashion photography, small eyebrow “YOUR STYLE. YOUR RULES.”, heading “Fashion That Moves With You.”, short brand copy, and working Explore Collection / Visit Our Stores buttons.
4. Four image-led category cards: Korean Edit, Unisex Collection, Women’s Wear, Imported & Surplus.
5. New Arrivals product grid with good product photography, names, price display, and clear enquiry/product actions. Clearly treat product data and prices as demo placeholders, not verified real stock/prices; avoid claiming real availability.
6. Wholesale and retail split section, with wholesale enquiry CTA.
7. Brand story section.
8. Two store cards with supplied addresses, call links using tel:9345926694 and tel:9363034644, and Google Maps search links based on each address.
9. Instagram gallery area linking to the official profile. Use relevant fashion imagery as visual placeholders; do not falsely claim a live Instagram API feed.
10. Contact/wholesale enquiry form with name, phone, business name optional, product interest, estimated quantity, preferred location, and message. Add validation and a clear success state; if no backend/email integration is configured, explain that it is a demo form and do not falsely claim it sent a message.
11. Footer with brand, category links, contact information, store locations and Instagram link.

FUNCTIONALITY:
- Responsive desktop/tablet/mobile design.
- Working navigation and section anchors.
- Category cards navigate to relevant collection views/sections.
- Product search and category filtering for the demo dataset.
- Product quick-view or product details interaction.
- WhatsApp enquiry links only when using a valid configured number; since the correct WhatsApp number is not specified, use a clearly editable configuration value and do not assume which phone is WhatsApp-enabled.
- Accessible labels, keyboard focus, semantic HTML, readable contrast, reduced-motion support, useful empty states, and optimized images.
- SEO metadata and sensible page title.
- Keep implementation clean and component-based using Lovable's default React/TypeScript/Tailwind stack.

Use attractive fashion photography placeholders and make the first screen visually impressive. Do not invent store hours, delivery/return policies, discounts, customer reviews, or confirmed prices. This is the first storefront prototype; prioritize visual quality and useful navigation over implementing payment checkout or a complex backend.
